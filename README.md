# EL-LENGUAJE-DE-LAS-SOMBRAS---CATALOGO-EXPERIMENTAL
El lenguaje de las sombras es un catálogo digital que reúne diferentes experimentaciones con los recursos del teatro de sombras. A través de fotografías, videos y registros del proceso, se exploran distintas maneras de combinar la iluminación, los colores, las superficies, los objetos y el movimiento para crear imágenes.
